# UI / UX 约定

## 页面与操作路径

- **项目运行**：项目资料 → 当前状态及下一步 → 启动/停止 → 快捷入口 → 可展开的任务与日志。
- **管理配置**：左侧导航保持固定，页面标题、用途说明、内容、保存状态和操作栏保持相同位置。
- **首次使用**：项目概览或项目管理中点击“创建项目/导入 JSON” → 项目概览 → 代码同步配置 → 任务配置 → 端口与用户入口 → 保存配置 → 测试认证/同步 → 项目运行。
- **任务配置**：列表选择任务；右侧分为基本信息、命令、环境、健康检查、重启与停止。切换分页保留全部草稿。
- **修改**：配置修改属于草稿，底部显示待保存状态。保存后生效；撤销恢复当前项目。代码同步要求先保存。
- **运行中**：配置不可修改，底部说明原因；停止后恢复编辑。存在未保存草稿时用户页主按钮会禁用，并提示先到管理配置保存。
- **危险操作**：同步代码页固定显示影响说明，点击同步即执行，不弹出二次确认；删除项目配置需要确认。删除列表条目属于草稿，可用撤销修改恢复。

## 视觉规则

使用深色页头/导航、浅灰工作区、白色内容卡片。文字和控件边界分别定义颜色，选中、焦点、禁用、只读与危险操作不得仅依赖默认主题。下拉箭头、数字增减和复选框使用内置图标，避免 QSS 覆盖原生标记后消失。

页面外边距 24，卡片内边距 20，普通行间距 16，按钮组间距 8。表单标签列统一 132 个逻辑像素；空间不足时换行。主窗口最小尺寸 900×560，内容页均可滚动以适配较高等效缩放。任务页使用内部滚动，外层不随全部字段增高。按钮组占用内容所需高度，不拉伸填满页面。

字段帮助紧邻输入内容，说明单位、执行顺序、覆盖关系与保存方式。空列表、未选择项目、未产生日志均提供下一步。端口摘要必须包含协议、地址、端口和所属任务。

## 验证

`cst-unit-ui` 检查任务分页往返的数据完整性、脚本多行文本、用户入口状态、空项目禁用、修改与撤销以及关闭流程。在 Windows CI 的 125%、150%、200% 缩放下执行。

CI 将每页、任务分页、空项目、失败提示和禁用状态的截图输出到 `Testing/screenshots/<scale>`，随 `CST-windows-test-logs` 产物提供。日志视图会把 JSON 日志格式化为“时间/级别/通道/事件/消息”的可读文本。截图用于人工检查对齐、边界、图标、可读性和滚动；自动测试不能替代真实 Windows 操作体验验收。
